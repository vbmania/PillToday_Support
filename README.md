PillToday는 하루 한 번 큼직한 버튼으로 약 복용을 체크하고, 요일별 알림과 위젯·워치에서 바로 완료를 표시할 수 있는 간단한 약 복용 트래커입니다. 앱 데이터는 기기 내(App Group)에만 저장되며 iCloud를 사용하지 않습니다.

## Contact / 문의
- 지원 채널: 이 저장소의 Issues 탭에 남겨 주세요.  
- 포함 정보: 기기 모델, iOS/watchOS 버전, 앱 버전(설정 > 앱 정보), 재현 단계, 스크린샷/로그(가능 시).

## FAQ (요약)
- **데이터 보관**: 약 복용 기록은 기기 내 App Group에 저장, iCloud/외부 서버로 전송하지 않음.
- **알림**: 로컬 알림만 사용. 요일/시간별 여러 알림과 스누즈를 지원.
- **Crashlytics**: 앱 안정성 진단용 크래시 로그만 수집(개인 식별정보 없음). 자세한 내용은 `privacy_policy_en.md` / `privacy_policy_ko.md` 참고.
- **동기화**: iCloud 동기화는 제공하지 않음. 필요 시 동일 Apple ID 기기마다 독립적으로 사용.

## English Summary
- Support: Please file an issue in this repository with device model, iOS/watchOS version, app version, repro steps, and screenshots/logs if available.
- Data: Stored on-device only (App Group). No iCloud, no external sync.
- Notifications: Local notifications with multiple weekday schedules and snooze.
- Crashlytics: Diagnostic crash reports only; no personal data. See privacy policies for details.
