# DUPCLEANER-PRIVACY-001 — Proposal

## 문제

공개 정책은 Crashlytics만 사용하고 광고·분석 SDK가 없다고 설명하지만 DupCleaner 1.1.0 소스에는 Firebase Analytics/Crashlytics, Google Mobile Ads/UMP 및 StoreKit이 포함되어 있다.

## 결과
