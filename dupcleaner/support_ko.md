# DupCleaner 지원 안내
최종 업데이트: 2025-12-06

## 앱 소개
- iPad에서 사용자가 선택한 폴더를 스캔해 중복 파일을 찾고, 안전하게 격리·정리하는 오프라인 앱입니다.
- 스캔 과정, 해시, 히스토리는 기기 내(App Group)에서만 저장·처리되며 서버로 전송하지 않습니다.

## 문의 방법
- **GitHub Issues**: 이 저장소의 Issues 탭에 남겨 주세요.
- 포함해 주시면 빠른 대응이 가능합니다:
  - 기기/OS 버전, 앱 버전(설정 > 앱 정보)
  - 선택한 폴더/볼륨 유형(로컬, 외장, 네트워크 등)
  - 실행한 스캔 옵션(자동 선택 여부 등)
  - 재현 단계, 스크린샷 또는 로그(가능 시)

## 자주 묻는 질문
- **데이터 저장/전송**: 파일 메타데이터와 해시는 로컬 App Group DB에만 저장되며 외부로 업로드하지 않습니다.
- **폴더 권한**: 파일 선택기는 사용자가 지정한 폴더/볼륨만 보안 북마크를 통해 접근합니다. 다른 경로에는 접근하지 않습니다.
- **Crashlytics**: 크래시 리포트만 수집하며 분석/광고/IDFA는 사용하지 않습니다. 설정 화면의 “Crashlytics 테스트 크래시”는 선택적으로 실행할 수 있습니다.
- **동기화**: iCloud/서버 동기화는 제공하지 않습니다. 기기별로 독립적으로 동작합니다.
- **데이터 삭제**: 앱 삭제 시 로컬 데이터가 함께 삭제됩니다. 폴더 접근을 철회하려면 파일 선택기에서 선택을 해제한 후 앱을 재시작해 주세요.
